Legendary Sword Knight

2D Platformer Python (Pygame) Action

An action-packed 2D platformer built with Python and Pygame. Players step into the shoes of a brave knight on a perilous quest to defeat the "Shadow King" and rescue the captured princess. The game features smooth physics-based movement, intricate character animations, dynamic boss AI state machines, and a robust socket-based multiplayer system for co-op gameplay.

Neon Hex

Puzzle Python (Pygame) Strategy

A sleek, neon-themed strategic puzzle game featuring grid-based mechanics. Designed with clean, minimalist aesthetics and vibrant visual effects, the game challenges players' logical thinking and spatial awareness. Built entirely with Pygame, it highlights efficient data structure management for tile states and optimized rendering loops for a seamless, smooth performance.

A fast-paced retro arcade tank shooter inspired by classic combat games. It features intense tactical battles, destructible environments, obstacle collision handling, and smart enemy AI behaviors.
